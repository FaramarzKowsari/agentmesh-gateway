# Execution Plan: v0.3 Adaptive Router

Status: completed

## Objective

Evolve AgentMesh from a static weighted router into a reproducible constrained routing system that can support research-quality experiments over cost, latency, quality, reliability, and quota pressure without ever selecting a protocol- or capability-infeasible provider.

## Core invariant

Optimization happens only over the feasible provider set.

```text
all configured providers
  -> model + circuit constraints
  -> protocol-losslessness constraints
  -> capability constraints
  -> quota exhaustion constraint
  -> feasible providers
  -> static or offline adaptive ranking
```

No optimization stage may reintroduce a provider removed by a hard feasibility gate.

## Accounting invariant

`cost_hint` remains a configured production-routing heuristic. Observed cost is calculated only from exact upstream/trace token counts plus explicit token prices. Missing observations remain missing.

## Latency invariant

Production latency scoring remains EWMA-based. Bounded p50/p95 values are evidence for diagnostics and simulation rather than an implicit production-policy change.

## Quota invariant

The request-quota window is a deterministic local control model that counts outbound provider attempts. It is not claimed to mirror vendor billing, TPM/RPM, or private rate-limit counters.

## Simulation invariant

Every policy replay starts from fresh deterministic state. Counterfactual outcomes must be supplied by the trace producer; AgentMesh does not manufacture missing provider outcomes, usage, or observed quality.

## Quality invariant

Contextual profile scores require benchmark ID, version, source, metric, and sample counts. Structural profile validation is not a certification of benchmark scientific quality.

## Adaptive-policy boundary

The adaptive policies are simulation-only research baselines. They carry no claim of empirical superiority or optimality and are not enabled by the HTTP gateway.

## Verification

All implementation PRs were required to pass Ruff and pytest through the repository CI matrix on Python 3.11, 3.12, and 3.13 before merge. The v0.3.0 release branch adds version and no-network simulation smoke coverage and repeats the same matrix before release merge.

## Deferred dimensions

The following are intentionally outside the v0.3 verified scope:

- vision/audio/context-length capability classification until representable losslessly;
- live adaptive/UCB production routing;
- real benchmark-result publication;
- provider-side quota/billing synchronization;
- cross-vendor reasoning/native-tool translation;
- exhaustive coding-client compatibility.

## Research outputs enabled

The completed substrate can support reproducible experiments over:

- cost-constrained latency minimization;
- quality-constrained cost minimization;
- quota-aware routing;
- contextual adaptation under hard feasibility constraints;
- exploration versus static baselines;
- sensitivity to capability constraints and provider failures.

Any performance result must be generated from a committed reproducible experiment or documented external dataset. Implementation alone is not empirical evidence.
