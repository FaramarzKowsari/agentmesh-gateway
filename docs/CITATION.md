# Citation and archival

AgentMesh Gateway is archived through the Zenodo–GitHub integration.

## DOI identifiers shown by Zenodo

Zenodo currently shows the repository DOI:

- `10.5281/zenodo.22069469`

The official Markdown badge snippet supplied by Zenodo for the archived release links to:

- `10.5281/zenodo.22069468`

For exact reproducibility of AgentMesh Gateway v0.3.0, cite the release-specific DOI used in `CITATION.cff`:

> Faramarz Kowsari. *AgentMesh Gateway*, version 0.3.0. Zenodo. https://doi.org/10.5281/zenodo.22069468

The repository-level DOI displayed by Zenodo can be used for repository discovery and version-family references:

> https://doi.org/10.5281/zenodo.22069469

## GitHub citation support

The repository root contains `CITATION.cff`. GitHub can use this file to expose a **Cite this repository** action and generate citation formats for users.

## Versioning note

Zenodo assigns persistent identifiers to archived records and supports versioned records. When a future AgentMesh release is archived, its release-specific DOI may differ. Update `CITATION.cff` for the exact released version while preserving repository-level discovery links where appropriate.
